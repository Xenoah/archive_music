OTODANA は、Xenoah の楽曲を聴いて、波形とテンポを確かめられる音楽アーカイブです。

曲ページを移動しても再生は続きます。ローカル音源の試聴と投稿パッケージの準備は、上部の Studio から利用できます。

- DEMO と記載された曲は動作確認用の合成音源です。
- 楽曲の利用条件は、各曲ページのライセンスを確認してください。
- BPM は推定値です。候補の選択や手動入力でビートグリッドを補正できます。
- 楽曲の投稿は Git コマンドで行い、GitHub Actions が公開フォルダーを構築します。

GitHub: https://github.com/Xenoah/archive_music
